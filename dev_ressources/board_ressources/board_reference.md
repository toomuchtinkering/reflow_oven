## Component datasheets

Available from each manufacturer by part number.

| Part | Role on the board |
|---|---|
| CH340C | USB-to-UART bridge |
| FM8002E | Audio power amplifier |
| ME6217 | 3.3 V LDO regulator |
| QD3579 | QDtech specification sheet (`QD3579-Specifications-A`) |
| ST7796S | LCD controller (Sitronix) |
| TP4054 | Li-ion battery charger |
| XPT2046 | Resistive touch controller |
